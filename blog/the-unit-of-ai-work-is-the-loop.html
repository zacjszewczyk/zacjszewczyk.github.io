The Unit of AI Work Is the Loop

By Zac Szewczyk on 2026/10/12 12:00:00 EST in Technology

A prompt can produce an answer, but an answer is seldom the whole job. Ask a model to develop a cyber analytic and it may return an SQL query one time, a Python script another, and a simple pattern match the third. In each case, I would get a plausible response in seconds; and in only one of those cases, if any at all, would the answer have the right shape — let alone whether it actually captures the behavior I care about, runs against the available data, and avoids burying analysts in noise remains an open question.

I increasingly think of useful AI work as a loop: establish an objective, supply context and tools, inspect intermediate results, evaluate the result against the objective, and correct what falls short.

Consider an analytic for suspicious remote logons. The objective is not to produce SQL; it is to identify a defined pattern of activity in a particular environment. The initial prompt matters, its initial output is important, but both are pieces of a system that improves over time.

Not every task needs an agent that plans and acts. A single request to reformat a list may be faster to inspect than a multi-step workflow is to construct. The practical question is therefore seldom simply how to write a better prompt. It is how to make progress visible, compare it with the intended result, and give the agent responsible — human or machine — a meaningful opportunity to adjust course.
